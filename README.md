# 処方の花 | Formula Bloom

公開版 v1.0.1：https://ginji001.github.io/formula-bloom-site/

日本語の全成分を花の比喩で読み解くWebアプリです。日本向けの成分表示を用いてください。

## GitHub Pages版でできること
- 147ブランドの検索。2163件の商品名登録を商品単位でまとめて表示。607処方に出典・確認日を付記
- 日本語全成分の手入力・写真OCR・花の生成、確認した未登録商品の端末内登録
- メーカー確認の部分成分 1296商品・48ブランドを参考の花として表示。全成分保存版とは別管理
- メーカー公式・海外販売店の英語INCI抜粋 26商品。公式3件と販売店5件の追加元も区別して表示し、国内版の処方と一致すると主張しません
- メーカー掲載の判明成分10商品の参考の花（全成分・配合順・処方全体を示さない）、それ以外の商品でも確認した成分だけを任意入力して部分表示
- 任意の端末内解析履歴、PNG作成

## ホーム画面・オフライン
- iPhoneはSafariの共有から「ホーム画面に追加」、Androidはブラウザのメニューからインストール
- 初回準備後、保存版検索・手入力・花生成・端末保存をオフラインで利用できます
- 写真OCRの初回準備と外部商品ページには通信が必要です
- 新しい版は更新ボタンで再読み込みします。端末保存データは削除しません
- 古い説明が残る場合はrefresh.htmlから最新版へ切り替え可能（端末内の商品・履歴を保持）

## 利用できないこと
- あらゆるサイトから自動で成分表を取得する機能（外部サイトは原文のコピー・確認から解析）
- 商品ページの文章・デザイン、レビューなどの転載
- 濃度・完成品の効果・安全性の保証

本試験版は一般向けの正式公開版ではなく、画像OCRには修正が必要な場合があります。
