# 処方の花｜Formula Bloom

公開版 v1.0.1：[アプリを開く](https://ginji001.github.io/formula-bloom-site/)

日本国内向け化粧品・医薬部外品の日本語成分を花で学ぶ、検索中心のWeb/PWAです。
商品名・ブランド名を検索し、容量・色・タイプを確認して選択してください。

- 優先2,020商品：全成分保存版600／一部参考1,248／未確認172。全商品網羅を意味しません。
- 一部成分は参考表示。出典・確認日を表示し、現物・最新ロットとの一致は保証しません。
- 未確認の成分・濃度・効能・安全性を推測せず、未収録は手入力・写真OCRへ案内します。
- 商品検索は端末内の保存データを使用。外部ページの成分表を自動取得する機能はありません。
- 入力・画像をアプリのサーバーへ送信・自動保存しません。履歴・商品登録は端末内への任意保存です。
- 初回準備後の検索・花生成はオフライン対応。OCRの初回準備と外部ページには通信が必要です。
- 全ブランド・全SKUの追加や無期限の商品収集は正式版の完成条件にしません。
