# 処方の花 | Formula Bloom

公開試験版：https://ginji001.github.io/formula-bloom-site/

日本語の全成分を花の比喩で読み解くWebアプリです。日本向けの成分表示を用いてください。

## GitHub Pages版でできること
- 147ブランドと登録商品名20件の検索（商品名・リンクのみ）
- 日本語全成分の手入力・写真OCR・花の生成
- A/B処方の比較、任意の端末内履歴、PNG作成

## 利用できないこと
- メーカー・通販サイトからのサーバー側の自動検索・成分取得
- 公式成分の保存版19件の再配布
- 濃度・完成品の効果・安全性の保証

本試験版は一般向けの正式公開版ではなく、画像OCRには修正が必要な場合があります。
本リポジトリは公開用のWeb素材のみを含み、開発用ソースリポジトリは別に非公開で管理しています。
