処方の花 v1.0.0 正式版

公開日：2026年11月5日。日本国内向け化粧品・医薬部外品の日本語成分表示を学ぶためのアプリです。確認できた出典付きデータで商品を検索し、一輪の花として処方を読み解けます。

できること

  • 商品名・ブランド名から登録製品を探し、確認済みの日本語全成分保存版から花を自動生成
  • メーカー等に記載された一部成分だけが確認できる場合は「参考の花」として明示
  • 未収録の製品は、全成分の手入力または写真OCRと原文確認から花を生成
  • 解析履歴とユーザー商品は本人が保存を選んだ場合のみ端末に記録
  • スマートフォンとPWAに対応し、保存版の情報はオフラインでも参照可能

172商品が未確認でも、アプリの正式版公開を妨げません。 未確認とは「公開されていない」という意味ではありません。公開情報を合理的に確認できないときは、推測で補わず、出典不足として区別します。

花の読み方と制限

花は一般的な役割を学ぶための比喩です。濃度・効能・安全性・品質・商品の優劣を示すものではありません。日本公式等の成分欄の保存時点と現行版、製品のバリエーション、医薬部外品の有効成分とその他成分を区別し、容器ラベル・ロットの一致は未確認と明示します。全成分の無許諾転載や成分の推測補完は行いません。

運営の連絡窓口（公開後の更新）

v1.0.0公開時点では窓口が未設置でした。v1.0.1で公開の不具合報告・日本語成分の訂正依頼窓口を設置しました。GitHubへの投稿は公開され、非公開の個別相談・個人情報の受付窓口ではありません。連絡先や運営者情報を創作して掲載しません。
